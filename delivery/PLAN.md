# PLAN — Entrelíneas

Vision (owner's words, durable): **make the film queryable** — a
pipeline that turns a given game into data you can query freely, with
deep soccer meaning, every answer a certified result or an honest
typed refusal, watchable as moments with evidence on the turf.
Standing posture (owner, 2026-07-07): everything is up for grabs —
the runtime is disposable if examination shows it missing the bar;
deep re-thinking of foundations is always encouraged. The artifact
system exists precisely so a rewrite keeps its oracles, specs, taste
contract, and decision history.

## Gates

### GATE 1 — "Send the link" (open-data demo)
The Film Room on a public entrelineas URL, demonstrable cold to a
discerning outsider with no one in the room.
Exit criteria: deploy oracle green against the live URL; design
constitution authored and the full perceptual stack passed (critic
panel, cold walkthrough, director delight pass on real device);
sealed exam (SCP2-E) passed with every answer certified-or-honestly-
refused; gallery instant, live asks demo-token-gated.
Kill/pivot rules: if Render-class hardware cannot serve the gallery
instantly, ship static-precomputed gallery + local live demos; if the
critic panel keeps failing the same surface after 3 rounds, the
surface is redesigned (director-authored), not polished.

### GATE 2 — "Upload your game here" (team pilot)
A team uploads match footage; the vision pipeline (validated ladder,
~$5/match GPU) turns it into canonical tracking; the same Film Room
queries it. Honest promise: processing takes a while; imputation is
never presented as observation; the query-fidelity table states
per-question what survives broadcast-grade tracking.
Entry: Gate 1 passed. Work: INT-0 (vision coords through the
canonical port), INT-1 (fidelity table), upload runbook + queue.
Kill/pivot rules: if vision-grade UNKNOWN share makes flagship
queries vacuous on real footage, pivot to permission-tracking-data
pilots (clubs with existing tracking exports) while the insist path
(better ball/team models) runs as investment; the pivot is a recorded
option, not a failure.

### GATE 3 — depth program (post-pilot, unsequenced)
More film → narrower intervals; vocabulary growth by demand evidence
(positional roles, overlap, line identity); remaining operators
(entity_set_algebra, spatial_join); numeric aggregation via the
field-domain mechanism; CAR ladder rungs 1-2 when a pitch needs them.
