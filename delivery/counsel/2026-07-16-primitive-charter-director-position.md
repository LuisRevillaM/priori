# Director's independent position — the missing primitive set
Sealed before reading any counsel. Anchor: every tactically relevant
situation is geometry + kinematics + time + relations; prefer FEW
ORTHOGONAL primitives whose compositions cover MANY questions over
a long list of bespoke ones.

## Design laws that govern every candidate
- Derived structure over observed positions is legal (deterministic
  geometry, not imputation) — but every definition is DECLARED and
  every structural primitive is TRI-STATE: when the structure is not
  identifiable (transition chaos), the answer is UNKNOWN, never a
  forced assignment.
- 2D tracking cannot see ball height: "long ball" is defined by
  distance/speed/trajectory-gap, never height; any height claim is a
  typed refusal.
- Velocity/acceleration are derivative estimates: estimation window
  declared once, globally.
- REGION as a first-class value is the keystone: one region algebra
  beats N bespoke zone primitives.

## Family A — team-shape geometry (the owner's seed, correctly a family)
A1. line_structure: per-frame clustering of a team's outfield players
    into ordered lines (back/mid/front), orientation-aware; emits
    line membership, height, stagger, and IDENTIFIABILITY (tri-state).
A2. inter_line_corridor: region between consecutive lines (the
    "between the lines" polygon), from A1.
A3. block_shape: compactness (hull area, width, depth), block height
    (distance of lowest line from own goal) — the "low block / high
    line" vocabulary.
A4. last_line_boundary: the offside-line geometry; "beyond the back
    line" as a region predicate.

## Family B — region algebra (the generalizer)
B1. region values: pitch partitions (thirds, halves, channels,
    half-spaces, penalty areas, zone-14) orientation-aware; PLUS
    dynamic regions imported from A (corridors, beyond-last-line).
B2. event_in_region / state_in_region predicates (reception in
    corridor, regain in attacking third, carrier in half-space).
B3. count_in_region: players of each team inside a region →
    numerical superiority/overload as a derived comparison.

## Family C — relational pressure (partially exists; formalize)
C1. pressure_on_carrier: nearest-defender distance + closing speed,
    thresholds declared (the fragile_possession_state machinery
    generalized to a reusable primitive).
C2. separation_at_event: receiver's distance to nearest marker at
    reception — "the free man," measurably.

## Family D — ball-travel classes (event-derived, mostly cheap)
D1. switch_of_play: lateral ball travel crossing >= N channels within
    T seconds (composable from pass events + B1 channels).
D2. long_ball: pass with declared length threshold + defined
    receiving-contest context; height REFUSED by law.
D3. progressive_pass (goalward progression per pass, mirroring the
    existing carry progression).
D4. entry events: final-third entry, box entry (B2 specializations —
    zero new machinery if B lands first).

## Family E — kinematic runs
E1. run_episode: sustained movement above declared speed with
    direction class (in-behind = toward last-line region, dropping,
    wide overlap); composes with A4/B for "runner beyond the line."

## Family F — transition-moment states (compositions, NOT new primitives)
rest_defense_shape = A3 evaluated at loss-moment; counterpress
window exists; defensive exposure = count ahead-of-ball at loss (B3
variant). Record as certified COMPOSITIONS to resist primitive bloat.

## Priority by demand evidence (owner's own questions, 2026-07-16)
1. B (region algebra) — unlocks pressing map depth, entries, zones.
2. A1+A2 — "receptions between the lines" (the owner's flagship ask).
3. C2 + group_by/extremum (exists) — "who's the receiver."
4. D1/D2 — "beat the block with a long ball," "failed to switch."
5. A3+F — "trapped on the wing," rest-defense reads.
6. E — runs in behind (needs A4).

## Anti-goals
No pitch-control/xT-style models (model-heavy, separate declared
tier, post-charter); no formation LABELS ("4-4-2") — structure yes,
taxonomy no (labels are commentary, not measurement); nothing that
imputes unobserved positions.
