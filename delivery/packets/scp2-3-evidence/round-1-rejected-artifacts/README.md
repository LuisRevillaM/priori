# SCP2-3 Round 1 Rejected Artifacts

These files are preserved only as the rejected round-1 evidence set discussed in
`delivery/packets/SCP2-3-REVIEW.md`. They are not round-2 evidence and are not
used by the round-2 report.

Round-2 evidence is produced by the committed
`scripts/packets/scp2_3_film_room_e2e.py` script into timestamped
`delivery/packets/scp2-3-evidence/runs/` directories, with script hash and run
timestamp embedded in each produced artifact.
