# Atlas Provenance

The raw atlas manifest in `raw/five_year_capability_manifest.yaml` is derived
from Priori (the company)'s authored material shared as context before this
project adopted the independent name Entrelíneas.

Entrelíneas preserves that provenance for attribution. The implementation,
runtime, tests, generated registry, and product surfaces in this repository are
built independently on public IDSSE/DFL data and do not imply Priori SDK/API
access, private Priori data access, production integration, endorsement, or
ownership.

Do not remove this file during project renames or registry regeneration. Update
it only if the atlas source provenance materially changes.
